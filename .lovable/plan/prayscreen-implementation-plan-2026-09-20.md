# PrayScreen implementation plan

## Scope
- Add PrayScreen as the second primary destination: Today → PrayScreen → Wallpapers → Quiz.
- Add a prominent starred PrayScreen feature below the main mockup and above Today tasks.
- Build Android permission onboarding, protected-app selection, daily reset windows, Sacred Pause, free and Pro modes.
- Mirror the same experience in the web preview with simulated device permissions and app blocking.

## Product behavior
- Free users can guard selected apps and complete a short scripture prayer to unlock until the next reset, with a fair minimum pass.
- Pro users get more guarded apps, ad-free pauses, schedules, and strict focus mode.
- Preserve Today, Wallpapers, Quiz, existing purchases, alarms, and all current content.

## Validation
- Check tab navigation, feature entry points, permission states, prayer flow, and light/dark styling.
- Run available static checks and inspect the web result at phone size.
